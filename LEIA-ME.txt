REVISÃO DOS CONCEITOS
HTML estrutura o conteúdo; CSS define sua apresentação; JavaScript controla
comportamentos. No formulário tradicional, o POST é seguido por um
redirecionamento e nova leitura da página.

Na SPA, preventDefault impede o envio padrão do formulário. O JavaScript
atualiza o DOM e envia JSON ao servidor, mantendo a página aberta.
Uma atualização local não prova que o servidor persistiu o dado.

Em React, props levam dados do componente pai ao filho. useState guarda
dados que mudam e provoca uma nova renderização. Os votos usam uma nova
lista, sem modificar a lista anterior. A média atribui +1 a good, 0 a
neutral e -1 a bad. O percentual positivo divide good pelo total.

Em outro terminal, execute pnpm server na raiz para usar a agenda.
O servidor usa 127.0.0.1:3001. O Vite encaminha /api-phonebook para ele.
Os contatos incluídos são fictícios. A geração de dist compila apenas o
frontend; uma publicação real da agenda também precisa hospedar a API.

Validação da Parte 2:
- Cadastro e persistência após recarregar.
- Filtro sem distinguir letras maiúsculas de minúsculas.
- Atualização de telefone com confirmação dentro da página.
- Cancelamento preserva o contato; confirmação permite excluir.
- Contato apagado no servidor antes da edição gera mensagem de erro e
  remove a referência antiga da tela.
- Países: resultados excessivos, ausência de resultados e escolha por botão.
- Consultas reais de tempo em Brasília e Londres.

A aplicação de países consulta o serviço público da Universidade de Helsinki
em https://studies.cs.helsinki.fi/restcountries/api/all e os dados de tempo
do Open-Meteo. Não requer chave de API para esta demonstração educacional.
